# Todo

Todo is a short C CLI tool made to let people easily manage their todo lists.

# Getting Started

To compile the file, run `gcc src/main.c -o build/todo.exe`, then run `todo help` to see available commands.

# Features

Todo records tasks locally in the current directory, which means your todo lists never get mixed up! An extremely simplistic and lightweight to add, delete, clear, and manage tasks, Todo is the perfect choice for doing instead of just planning.
